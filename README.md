# Battleverse Launcher

Официальный лаунчер Battleverse (Tauri + Rust + HTML/JS/CSS).

## Особенности сборки
- **Полная русская локализация**: Мастер установки NSIS полностью переведён на русский язык.
- **Современный визуальный стиль**: Фирменная тёмная графика, неоновые акценты Battleverse IV и тактическая стилистика.
- **Требование к диску**: ~1.0 ГБ свободного места под игровой клиент, текстуры и моды.
- **Официальный сайт проекта**: [https://battleverseiv.netlify.app/](https://battleverseiv.netlify.app/)

## Сборка из исходников
```bash
cd src-tauri
cargo tauri build
```
